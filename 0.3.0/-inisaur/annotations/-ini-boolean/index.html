IniBoolean

@Target(allowedTargets = [AnnotationTarget.PROPERTY])
annotation class IniBoolean(val capitalized: Boolean = true)(source)

Configures how a Boolean property should be serialized in INI format.

This annotation allows customization of boolean value representation in INI files, with the option to use capitalized (True/False) or lowercase (true/false) formats.

Example:

@IniSerializable
data class ServerConfig(
    @IniBoolean(capitalized = true)
    val enablePvP: Boolean,

    @IniBoolean(capitalized = false)
    val allowBuildingDamage: Boolean
)
